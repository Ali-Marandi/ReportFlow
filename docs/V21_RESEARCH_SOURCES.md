|---|---|---|
| Copilot و semantic model | Copilot باید بر semantic model آماده‌شده و context/permissionهای همان کاربر تکیه کند؛ کیفیت داده و descriptionهای مدل بر قابلیت اعتماد پاسخ اثر مستقیم دارد. | [Microsoft Learn — Copilot for Power BI](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-introduction) |
| حریم Copilot | Copilot برای پاسخ‌های داده‌ای از دادهٔ semantic model و prompt استفاده می‌کند؛ بنابراین scope داده، permission و حاکمیت model باید پیش از LLM enforce شود. | [Microsoft Learn — Privacy, security, and responsible use](https://learn.microsoft.com/en-us/fabric/fundamentals/copilot-power-bi-privacy-security) |
| Semantic Layer | semantic layer یک source of truth برای metric/dimension و business logic است؛ deterministic calculation، version control و lineage، دقت AI و قابلیت audit را افزایش می‌دهند. | [Google Cloud — Looker semantic layer and trusted AI](https://cloud.google.com/blog/products/business-intelligence/how-lookers-semantic-layer-enhances-gen-ai-trustworthiness) |
| Dynamic bursting | mapping recipient-to-filter/parameter باید در semantic model جدا و data-driven نگه‌داری شود؛ dynamic delivery با latest mapping اجرا و single-value filterها باید validate شوند. | [Microsoft Learn — Dynamic per-recipient subscriptions](https://learn.microsoft.com/en-us/power-bi/collaborate-share/power-bi-dynamic-report-subscriptions) |
| Delivery controls | attachment/privacy label، approval، schedule/window، recipient limit و failure feedback از کنترل‌های ضروری distribution هستند. | [Microsoft Learn — Dynamic subscriptions for paginated reports](https://learn.microsoft.com/en-us/power-bi/collaborate-share/dynamic-subscriptions) |

RLS default-deny است وقتی row security فعال باشد ولی policy نداشته باشد. | [PostgreSQL — SSL support](https://www.postgresql.org/docs/current/libpq-ssl.html) · [PostgreSQL — Row security policies](https://www.postgresql.org/docs/current/ddl-rowsecurity.html) |
| SQL Server security | ODBC encryption به‌طور پیش‌فرض در driver 18+ فعال است؛ production باید certificate validation را حفظ کند و از `TrustServerCertificate=yes` پرهیز کند. | [Microsoft Learn — ODBC connection encryption](https://learn.microsoft.com/en-us/sql/connect/odbc/connection-troubleshooting?view=sql-server-ver17) |
| GTM Enterprise | برنامهٔ GTM باید customer definition، value proposition، pricing/packaging، sales/distribution، launch operations، KPI و governance را در یک برنامهٔ زمان‌دار و قابل‌اندازه‌گیری یکپارچه کند؛ B2B Enterprise معمولاً بر pilot، مشاوره و چرخهٔ خرید چندذی‌نفعی تکیه دارد. | [Stripe — GTM strategy guide](https://stripe.com/resources/more/what-is-a-go-to-market-strategy-a-quick-gtm-guide-for-startups) |
